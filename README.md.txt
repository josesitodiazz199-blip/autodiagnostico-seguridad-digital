# Plataforma Web para el Autodiagnóstico de Seguridad Digital

Este repositorio contiene el código fuente del prototipo funcional desarrollado para el proyecto de grado "Plataforma web para el autodiagnóstico de seguridad digital en pequeñas organizaciones del Líbano, Tolima".

## Autores
* José Esteban Díaz Joya
* Ricardo Valderrama Madrigal

## Descripción del Prototipo
El prototipo fue desarrollado utilizando **HTML, CSS y JavaScript**. Consiste en un cuestionario interactivo de 15 preguntas divididas en 5 dimensiones de seguridad. Al finalizar, el sistema calcula un porcentaje orientativo de cumplimiento, clasifica el resultado en tres niveles y genera recomendaciones personalizadas.

## Características Principales
* Interfaz amigable y adaptable a dispositivos móviles (Responsive).
* Validación de preguntas obligatorias.
* Cálculo automático de porcentajes y clasificación.
* Generación dinámica de recomendaciones.
* No almacena datos personales (privacidad por diseño).

## Cómo ejecutar el prototipo
Para probar el prototipo, simplemente descarga el archivo `prototipo.html` y ábrelo en cualquier navegador web (Chrome, Firefox, Edge, etc.). No requiere la instalación de servidores locales ni bases de datos.
